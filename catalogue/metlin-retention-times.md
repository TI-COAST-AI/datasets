# METLIN Small-Molecule Retention-Time Dataset

A dataset for machine-learning-based prediction of small-molecule
chromatographic retention times.

## Source

[Original dataset on Figshare](https://figshare.com/articles/dataset/The_METLIN_small_molecule_dataset_for_machine_learning-based_retention_time_prediction/8038913)

Use the original source for downloads, version information,
file descriptions, and access conditions.

## Contents

Small-molecule retention-time data intended for developing
machine-learning prediction models.

The current file contents, number of records, identifiers, and units
have not yet been verified for this catalogue. Check the source
documentation before use.

## Suggested uses

- Develop and evaluate retention-time prediction models.
- Compare molecular representations and regression methods.
- Explore relationships between molecular structure and retention.
- Teach data preparation, model evaluation, and explainable AI.

## Data quality and preparation

Retention times depend on the chromatographic method.
Check the experimental conditions and retention-time units before
combining these data with other sources.

Inspect missing values, repeated compounds, and molecular identifiers
before training. Keep repeated measurements of the same compound
together when evaluating predictions for unseen compounds.

### Potential overlap with RepoRT

RepoRT lists the associated Domingo-Almenara publication among its
data sources. Check for overlapping records before combining these
collections or using one for training and the other for testing.
