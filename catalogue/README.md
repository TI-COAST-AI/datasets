# Dataset Catalogue

Browse chemistry and analytical chemistry datasets here.

Each dataset will have its own page describing:
- What the dataset contains
- Original creators and source link
- Licence and access conditions
- File formats, column definitions, and units
- Suggested teaching or machine-learning applications
- Known limitations and recommended citation

Dataset entries will be added as they are reviewed.
